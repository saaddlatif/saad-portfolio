About

I started as a software engineer, so I design things I know can be built.

I studied computer science at FAST-NU and wrote Java for a payments platform before moving into design. That background shows up in how I work: I build design systems that developers actually adopt, I prototype with real logic, and when a static mockup can't answer the question, I build the thing.

Right now I design hiring, analytics and AI products at Arbisoft for US clients. I also run usability tests, write accessibility standards to W3C ARIA, and host internal sessions on Figma variables and advanced prototyping.
